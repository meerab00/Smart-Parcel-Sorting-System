How the model works

1. ℤ₄: orientation is represented by a number 0–3. The required turn is (target − current) mod 4.

2. D₄: each parcel can be rotated or reflected. A flip is counted as a reflection operation.

3. Sₙ: sorting creates a permutation of parcel positions, grouping parcels by destination.

This is a software simulation of sorting logic, not a physical conveyor or industrial scanner.

Finite Abelian Group · Clock Arithmetic (Z₁₂)

Solved example: It is 9:00 now. What time will it be after 7 hours?

Solution

(9 + 7) mod 12 = 16 mod 12 = 4. Final time: 4:00.

Permutation Group (Sₙ) · Parcel Arrangement

Solved example: arrange parcels by destination priority: Islamabad → Karachi → Lahore → Multan.

Initial order

P1 Lahore, P2 Multan, P3 Karachi, P4 Lahore, P5 Islamabad, P6 Multan

Final order

P5, P3, P1, P4, P2, P6

Permutation

π = (5, 3, 1, 4, 2, 6)

Inversions

(5,3), (5,1), (5,4), (5,2), (3,1), (3,2), (4,2) = 7. Minimum adjacent swaps = 7.

Dihedral Group (D₄) · Rubik's Cube Face Symmetry

Solved example: the square face has four rotations and four reflections, giving eight symmetries.

Group elements

Rotations: e, r, r², r³ (0°, 90°, 180°, 270°).

Reflections: s, rs, r²s, r³s.

Worked rules

Four quarter-turns: r⁴ = e. Two reflections: s² = e.

Using the D₄ multiplication rule, sr = r⁻¹s. So rotation and reflection do not commute in general.
