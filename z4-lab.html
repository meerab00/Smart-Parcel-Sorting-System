ℤ₄ Orientation Optimizer

Real problem: a parcel must face a specified direction before it enters a handling or label-reading station. Find the shortest valid quarter-turn route.

Enter parcel orientation

Each state represents one quarter-turn: 0°, 90°, 180° or 270°.

Ready

Choose the current and required direction, then calculate.

Why ℤ₄?

Orientation states form the set {0, 1, 2, 3} with addition modulo 4. A full turn returns to the starting state, so 4 ≡ 0 (mod 4).

Clockwise turns = (target − current + 4) mod 4

This model assumes a parcel can be turned in 90° increments. It does not detect orientation automatically or move a physical parcel.
