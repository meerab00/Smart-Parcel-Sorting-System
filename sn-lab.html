Sₙ Parcel Sequence Optimizer

Real problem: parcels arrive in a mixed order but must be arranged by destination before dispatch. Measure how far the current order is from the target order.

Enter the arrival sequence

One parcel per line, using this format: Parcel ID, Destination. The destination priority defines the required dispatch order.

Ready

Add parcels and run the optimizer to compare the sequences.

Mathematical meaning

The initial parcel positions are mapped to their final positions by a permutation in Sₙ. An inversion is a pair of parcels that appears in the opposite order from the target. The inversion count equals the minimum number of adjacent swaps needed to reach the target sequence.

This model uses destination priority and adjacent swaps as a mathematical measure. It is a dispatch-order simulation, not a live warehouse conveyor controller.
